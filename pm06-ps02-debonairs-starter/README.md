# Debonairs Pizza menu clone (PM-06 PS02 — PA0206)

1. Open `reference-debonairs-menu.png` (also shown in the Zaio task) as your design target.
2. Build the page in `index.html` and `css/styles.css`.
3. Use images from `assets/` (logo + three pizza photos).
4. Edit `js/footer.js` — set `YOUR_NAME` to your full name. The footer shows **name + today's date** bottom-right.
5. Screenshot your finished page in the browser for submission.
